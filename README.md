# Decision Readiness Platform

An exploratory data engineering project investigating how North Carolina public weather data
and synthetic emergency-logistics data can support regional supply-risk decisions.

## Status

Data discovery and feasibility analysis.

## Initial decision question

Which locations are at risk of falling below critical supply levels during
severe weather?

## Current work

- Evaluating public weather and geographic datasets
- Defining synthetic logistics entities and assumptions
- Testing whether the sources can be joined reliably

## Information safety

This independent portfolio project uses public or synthetic data and contains
no government, customer, proprietary, controlled, or operational information.
